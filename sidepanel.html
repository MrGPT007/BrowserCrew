    Cloud AI sends approved job text over the internet. Local AI keeps model requests on your computer when you use a loopback address such as 127.0.0.1.

    This is the model BrowserCrew asks to do the job. Example: gpt-5.6 for OpenAI, or the exact model name loaded in LM Studio.

    💡 Use a model that can follow instructions and return JSON. If the name is wrong, the connection test will tell you before a job starts.

    This is the web address of your AI service. You usually do not need to change the preset.

    📌 Examples: OpenAI → https://api.openai.com/v1 · LM Studio → http://127.0.0.1:1234/v1 · Ollama → http://127.0.0.1:11434/v1

    BrowserCrew uses this key only to talk to the selected AI service. The key is kept in Chrome’s session storage and is not written into task history.

    🔒 Recommended: use a dedicated API key with spending limits. Local LM Studio and Ollama usually do not need a key.
