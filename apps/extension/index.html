ONE CONNECTION. YOUR CHOICE.

Meet your AI.

Use an AI service or a model on this computer. No BrowserCrew account needed.

Choose AI service if you have a service key. Choose On this computer if you already run LM Studio or Ollama. Your local server may have its own network behavior.

This is where your request and chosen page text go. For OpenAI, keep https://api.openai.com/v1. Other services must support the same tool-calling format. For local AI, use the address shown by your running model server.

Address examples

OpenAI: https://api.openai.com/v1
LM Studio: http://127.0.0.1:1234/v1
Ollama: http://127.0.0.1:11434/v1
Local addresses must point to this computer. Local servers need a loaded model with tool support. These presets still need a real connection test on your computer.

Choose the model that will do the work. Copy its exact name from your service or local model app. Use a model that supports tools; the connection test checks this before saving.

This key lets BrowserCrew use your AI service. It is kept only for this browser session and is never sent to a page. A local model may not need a key. A ChatGPT or Claude subscription is not an API key and is not connected by this screen.

Testing sends a small sample request to the server above. It may use a small amount of paid service credit. No browser page is read during the test.

What’s here today.

v0.1 · Development preview

Read up to five selected tabs, gather facts with exact source quotes, or prepare a form for your review. Pause, take over, stop, save tasks, and export results.

What a result check means

Research checks that quoted text occurs in a page observation and includes the reported value. It does not prove a website is correct or independently judge every part of your request. Form checks confirm field values immediately after filling; they do not prove a server saved them.

What comes later

Navigation and clicks, directory exports, invoice downloads, saved-record verification, screenshots, more AI providers, reusable workflows, connected tools, shared memory, and specialist agents are planned. They are not available yet.

Where it runs

The extension runs in Chrome on your computer. AI service requests run with your chosen provider. Local model requests go to the server on your computer. BrowserCrew has no hosted task server and cannot work when Chrome is closed.

Before wider use

This preview needs real cloud and local model trials, Windows checks, broader workflow tests, and accessibility review. It is not a Chrome Web Store release.
